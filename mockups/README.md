# Theme proposals (not for production)

Static HTML previews of three whole-page directions for chipwavestudio.com.
They are not wired into `public/` and must not be deployed until one is chosen.

- `a/` tactile studio desk: dark graphite, cream and orange, editorial type, wide product photo.
- `b/` step desk: cream and ink, hard offsets, a sequencer rail, stepped download rows.
- `c/` midnight workstation: screenshot-first, track lanes, deep blue and teal.

Facts match the live site as of the Linux 0.2.21.0 download update. Windows and Mac stay on 0.2.20.0.

Newsreader, Syne, and IBM Plex in `fonts/` are SIL Open Font License, for these previews only. Atkinson Hyperlegible is the font already used on the live site.
